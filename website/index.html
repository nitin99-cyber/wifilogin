// Verified Capabilities

Engineered for campus reliability.

Cyberoam captive portals expire sessions throughout the day. MMMUT WiFi Auto Login manages connections quietly without browser tabs.

01 / Session Recovery

Automatic reconnection when sessions expire.

Re-authenticates automatically when the Cyberoam portal times out or when your laptop wakes from sleep. Eliminates abrupt disconnects in computer labs, lecture halls, and hostels.

02 / Device Limit Failover

Two-account smart failover.

When your primary account hits the portal's "Maximum Login Limit Reached" error from an active phone session, the application switches to Account 2 without prompting.

03 / Minimal Overhead

Boot popup and tray monitor.

A compact boot toast confirms connection in ~4 seconds and auto-closes. Access settings, manual reconnect, and portal logout anytime from the notification area.

Security Architecture

Local DPAPI Vault

Credentials are saved into Windows Credential Manager (keyring) with user session encryption. No plain-text files.

Network Optimization

Netsh Wi-Fi Scanner

Scans visible campus networks and associates with the strongest MMMUT access point before initiating portal authentication.

Session Control

Portal Logout Mode 193

Explicit support for Cyberoam Mode 193 lets you disconnect all sessions cleanly before leaving campus.

// Setup Sequence

Get started in four steps.

Standard user privileges only. No administrator rights, drivers, or registry tampering required.

01

Download

Obtain the verified Windows installer from the direct download button or GitHub releases.

02

Install

Run MMMUT_WiFi_Auto_Login_Setup.exe. Desktop and Startup shortcuts are configured.

03

Configure

Enter your student credentials once. Passwords are saved in Windows Credential Manager.

04

Stay Connected

The utility runs quietly in the background, recovering sessions whenever you join campus Wi-Fi.

// Privacy Guarantee

Your credentials never leave your machine.

MMMUT WiFi Auto Login has zero remote telemetry. Every line of Python and Inno Setup configuration is auditable on GitHub.

Local Keyring Storage

Credentials are saved under service MMMUT-WIFI-AUTOLOGIN using OS-level encrypted storage.

Zero Remote Telemetry

The desktop client communicates exclusively with local gateway 172.16.1.3:8090 and a standard connectivity check.

Standard User Privileges

Runs entirely within normal Windows user permissions without administrative elevation.
