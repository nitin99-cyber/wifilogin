Features

Everything you need to stay connected at MMMUT — automatically.

Automatic Login

Automatically logs you into the Cyberoam portal when your device connects to the MMMUT network.

Secure Credential Storage

Credentials are securely stored using Windows Credential Manager — never saved in plain text.

Multiple Account Support

Save and manage multiple accounts. The app tries each one until login succeeds.

Automatic Startup

Launches automatically when Windows starts so you never have to think about logging in.

Lightweight

Runs quickly and uses very little system resources. No background processes hogging your RAM.

Open Source

Source code is available for inspection on GitHub. Transparent and community-driven.

Privacy & Security

Your data stays on your computer. Always.

This application is designed with privacy in mind.

  • Your credentials never leave your computer.
  • Passwords are stored securely using Windows Credential Manager.
  • No analytics are collected by the application itself.
  • No personal information is transmitted to the developer.
  • The application communicates only with the official MMMUT Cyberoam login portal.
