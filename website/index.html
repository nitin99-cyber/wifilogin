Frequently Asked Questions

Common questions about the application.

Is it safe?

Yes. The application only communicates with the official MMMUT Cyberoam login portal. Your credentials are stored securely in Windows Credential Manager and never leave your computer. The full source code is available on GitHub for inspection.

How are passwords stored?

Passwords are stored using Windows Credential Manager — the same secure vault Windows uses for its own passwords. They are never saved in plain text files.

Does it require Python?

No. The application is packaged as a standalone executable using PyInstaller. No Python installation required.

Does it work offline?

The app needs a network connection to reach the MMMUT Cyberoam portal. It monitors your Wi-Fi connection and automatically logs in when you're connected to the campus network.

Can I uninstall anytime?

Absolutely. Go to Windows Settings → Apps → Installed Apps and uninstall like any other program. Your saved credentials in Credential Manager will remain untouched.

Will it support Linux?

Currently Windows-only. Linux and macOS support may be added in future versions based on community interest.
